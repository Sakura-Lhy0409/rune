=== MLComputeUnits
enum
 
MLComputeUnits
Overview
Use this enumeration to set or inspect the processing units you allow a model to use when it makes a prediction.
Use 
 to allow the OS to select the best processing unit to use (including the neural engine, if available).
Use 
 to restrict the model to the CPU, if your app might run in the background or runs other GPU intensive tasks.
